# خشت (Khisht) MVP

نسخهٔ مستقل و نمایشی پلتفرم «خشت» برای توکن‌سازی مفهومی پروژه‌های ملکی. این پروژه در پوشهٔ جداگانهٔ `khisht-mvp` ساخته شده تا با پروژهٔ قبلی `metrika-mvp` قاطی نشود.

هویت بصری بر اساس لوگوی لوزی قرمز و خطوط ساختمان طراحی شده است. عکس‌های معماری داخل `public/projects` تصاویر تولیدشدهٔ نمایشی‌اند و به ملک واقعی اشاره نمی‌کنند.

## اجرا در ویندوز و VS Code

در PowerShell، وارد همین پوشه شوید:

```powershell
cd "C:\Users\Ali\.gapcode\chats\2026-08-20\khisht-mvp"
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید. برای اجرای نسخهٔ production:

```powershell
npm run build
npm run start
```

## دستورهای بررسی

```powershell
npm run lint
npm run typecheck
npm run build
```

## مسیرهای اصلی

- `/` صفحهٔ اصلی، معرفی مدل توکن و مسیر بانک فرضی → توکن طلا → توکن خشت
- `/projects` کتابخانهٔ پروژه‌ها با جست‌وجو و فیلتر
- `/projects/shahrak-west` جزئیات پروژه، قیمت توکن و شبیه‌ساز مبلغ
- `/projects/shahrak-west/documents` نمودار پیشرفت، تصاویر مراحل و اتاق اسناد سطح‌بندی‌شده
- `/market` بازار ثانویهٔ نمایشی با دفتر سفارش و حداقل معاملهٔ یک میلیارد تومان
- `/market/shahrak-west` بازار پروژه‌محور همان توکن با دفتر سفارش اختصاصی
- `/portfolio` سبد توکن‌های خشت/طلا، قفل نمونه و حفاظت فرضی
- `/tiers` انتخاب سطح تجربهٔ برنزی، نقره‌ای، طلایی یا تیتانیومی
- `/dashboard` داشبورد نمونهٔ سرمایه‌گذار
- `/how-it-works` توضیح چرخهٔ محصول، گواهی مالکیت دیجیتال فرضی و ریسک‌ها

## مدل محصول در این دمو

هر واحد دیجیتال «توکن خشت» نام دارد. سه مسیر نمایشی در شبیه‌ساز وجود دارد: بازار ثانویهٔ پویا، نگهداری نمونهٔ ۲۴ ماهه و حفاظت سرمایهٔ فرضی با کارمزد ۱٪ و تبدیل احتمالی به توکن طلا. ارزش‌گذاری، پیشرفت ساخت، اسناد و گواهی مالکیت دیجیتال در این نسخه داده‌نما هستند.
