# خشت — پلتفرم کامل سرمایه‌گذاری املاک

این پروژه یک اپ کامل Next.js برای نمایش تجربهٔ سرمایه‌گذاری خرد در املاک است. نسخهٔ فعلی شامل صفحهٔ اصلی، پروژه‌ها، جزئیات پروژه، بازار ثانویه، داشبورد سرمایه‌گذار، احراز هویت، پنل ادمین، پروفایل، مستندات و API نمایشی است.

## اجرا در VS Code

1. پوشهٔ زیر را با `File → Open Folder` در VS Code باز کنید:

   ```text
   C:\Users\Ali\.gapcode\chats\2026-09-06\https-app-bricks-co-https-go-ai-os-پرامپت-طراحی\khesht-studio
   ```

2. ترمینال VS Code را باز کنید و اجرا کنید:

   ```powershell
   npm install
   npm run dev
   ```

3. صفحه را در آدرس زیر باز کنید:

   ```text
   http://localhost:3000
   ```

## دستورهای بررسی و انتشار

```powershell
npm run lint
npm run typecheck
npm run build
npm run start
```

## ساختار کلیدی

```text
app/                 صفحات و کامپوننت‌های Next.js
app/dashboard/       داشبورد سرمایه‌گذار
app/admin/           پنل ادمین نمایشی
app/projects/        فهرست و جزئیات پروژه‌ها
app/market/          بازار ثانویه نمایشی
app/api/             API mock
lib/                 داده‌ها و منطق mock backend
public/              لوگو و تصاویر واقعی رابط کاربری
```

## صفحات اصلی

- `/` صفحهٔ اصلی با تصویر معماری و موشن آغازین
- `/projects` فرصت‌های سرمایه‌گذاری
- `/projects/shahrak-west` جزئیات پروژه و شبیه‌ساز سرمایه‌گذاری
- `/dashboard` داشبورد سرمایه‌گذار
- `/market` بازار ثانویه
- `/portfolio` سبد سرمایه‌گذاری
- `/kyc` احراز هویت
- `/admin` پنل مدیریت نمایشی
