# خشت (Khesht) — پلتفرم سرمایه‌گذاری خرد در املاک

یک وب‌سایت کامل فارسی/RTL برای پلتفرم سرمایه‌گذاری جمعی در پروژه‌های املاک، با الهام از ساختار و سبک بصری Bricks.co، اما با هویت بصری کاملاً اختصاصی.

## ویژگی‌ها

- طراحی مدرن، مینیمال و پریمیوم با فضای سفید زیاد و کارت‌های بزرگ گوشه‌گرد
- RTL و فارسی به صورت کامل (راست‌چین، اعداد فارسی، تایپوگرافی Vazirmatn)
- پالت رنگی اختصاصی: سبز اعتماد، طلایی CTA، پس‌زمینه روشن
- تصویرسازی‌های SVG اختصاصی به جای تصاویر استوک
- کاملاً ریسپانسیو برای دسکتاپ، تبلت و موبایل
- انیمیشن‌های نرم و ظریف: hover effects، fade-up reveal، floating card
- بدون وابستگی خارجی — فقط HTML, CSS, JavaScript خالص

## ساختار پروژه

```
khesht/
├── index.html                 # صفحه اصلی
├── project.html               # صفحه جزئیات پروژه
├── assets/
│   ├── css/
│   │   └── style.css          # تمام استایل‌ها
│   └── js/
│       ├── data.js            # داده‌های نمونه پروژه‌ها
│       ├── main.js            # منطق صفحه اصلی
│       └── project.js         # منطق صفحه جزئیات
└── README.md
```

## نحوه اجرا

فایل index.html را در مرورگر باز کنید یا با سرور محلی:

```bash
cd khesht
python -m http.server 8000
```

سپس به http://localhost:8000 بروید.

## یادداشت‌ها

- تمام اعداد و پروژه‌ها نمونه هستند؛ در نسخه نهایی باید از API دریافت شوند
- تصویرسازی‌ها با SVG procedural تولید می‌شوند
- هشدارهای قانونی سرمایه‌گذاری در فوتر درج شده‌اند
